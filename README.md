# Практическая работа — Калькулятор стоимости визиток (JS + DOM)

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Создан интерактивный калькулятор на чистом JavaScript (без jQuery), позволяющий выбирать визитки и динамически подсчитывать их количество и общую стоимость.

## Что реализовано
- **Выбор элементов:** пользователь кликает по карточкам визиток.
- **Визуальная индикация:** выбранная карточка выделяется черной рамкой и немного уменьшается.
- **Динамический подсчёт:** в реальном времени обновляется количество выбранных элементов и их общая сумма.
- **Хранение данных:** цена каждой визитки задана в HTML через кастомный атрибут `data-price`.
- **Работа с DOM:** используется `querySelectorAll`, `addEventListener`, `classList.toggle`, `dataset` и `textContent`.
- **Адаптивность:** CSS Grid автоматически перестраивает сетку на мобильных устройствах.

## Технологии
- HTML5
- CSS3 (Grid, Flexbox, transitions)
- JavaScript (ES6, работа с DOM)

## Файлы
- `index.html` — разметка страницы;
- `css/style.css` — стили и адаптив;
- `js/script.js` — логика подсчёта стоимости.
